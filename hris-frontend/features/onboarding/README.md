# Onboarding & Offboarding Feature Module

This module manages employee onboarding and offboarding workflows, department-level checklists (HR, IT, Finance, Manager), and task progress tracking.

## Directory Structure
- `api/`: Custom SWR hook (`use-onboarding.ts`).
- `components/`: UI components (`process-table.tsx`, `process-start-dialog.tsx`, `process-view-drawer.tsx`).
- `types/`: Typescript interfaces & helper functions (`onboarding.ts`).
