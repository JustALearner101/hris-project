# Announcement Feature Module

This module manages broadcast announcements, audience targeting, channels, and engagement metrics across the company.

## Directory Structure
- `api/`: Custom SWR hook (`use-announcement.ts`).
- `components/`: UI components (`announcement-table.tsx`, `announcement-form-dialog.tsx`, `announcement-view-drawer.tsx`).
- `types/`: Typescript interface definitions (`announcement.ts`).
