# Release Roadmap

## Release Phases

- **Wave 1 (Foundational Release)**: Core HR, Attendance, Leave, Payroll (Indonesia).
- **Wave 2**: ATS / Onboarding, Expenses, Asset Management.
- **Wave 3**: Performance, Learning, Engagement.

---

## API Versioning & Deprecation Policy

- **Versioning**: API versioning is handled via the URL path (e.g., `/v{n}`).
- **Support Lifecycle**: A minimum of 12 months support is provided per version.
- **Deprecation**: Major changes will be notified via email and changelogs. The `Deprecation` and `Sunset` headers will be included in responses from legacy endpoints.

---

## SLA Targets & Support

- **Uptime**: 99.9% availability in production (excluding scheduled maintenance of maximum 4 hours per month).
- **Response Time**: Priority 1 (P1) ticket response time is ≤ 30 minutes.
- **Resolution Time**: P1 ticket resolution time is ≤ 8 hours.
- **Maintenance Schedule**: Scheduled maintenance will be announced at least 3 days (H-3) in advance, with a maximum downtime of 4 hours per month.
